# 任务 05：界面和交互打磨

先读 `CLAUDE.md`；`docs/plan.md` 和 `docs/local.md` 存在时也读。第三版已验收并发布 `v0.3.0`，本任务只改界面和操作手感，不加新功能，不改数据模型和备份格式。

## 目标

现在的界面是一项项功能加出来的，像工具后台，维护者的评价是「太丑、太原始」。这一版重做视觉，同时让手指操作更顺，读的时候更干净：

- 有统一、耐看的视觉风格，不再像默认控件拼出来的；
- 阅读时屏幕尽量留给正文；
- 手指点得准，不用瞄准；
- 书架、设置这些页面用满平板横屏；
- 删除等确认用 App 自己的样式，操作有反馈。

## 范围

### 修复：选中工具栏不消失（第一个提交）

工具栏只在缓存被清除时才消失，而缓存只有点工具栏上的按钮才清。从代码能确认的路径：

- 选中文字后，点顶栏的「整篇提问」「笔记」，或点已有划线的「查看对话」打开面板，缓存不清；
- 选中文字后点别处取消选中，缓存也不清。

还有一条要到真机确认：安卓上 `removeAllRanges` 之后，如果系统选区没有马上消失，晚到的 `selectionchange` 可能把缓存写回来。

修法：

- 面板打开或切换时，统一清除缓存和选区；
- 点击正文且选区已空时，清除缓存；
- 刚清除的选区如果原样再次上报，忽略，直到选区真正变空。

「点工具栏按钮时选区被系统清掉，缓存必须还在」这条约定不变。

### 视觉改版

- 用设计变量定下一套规则：颜色、字号层级、圆角、阴影、间距，所有页面都从这里取，三种主题都要有。
- 重做按钮、标签、输入框、卡片、菜单和面板的样式。
- 选中工具栏改成悬浮的圆角条，和正文有明显层次。
- 不打包新字体，用系统字体，靠字号和字重建立层次。

### 阅读页

- 下滑阅读时顶栏自动收起，上滑或点正文中间时出现。选中文字、搜索、面板打开时不收起。
- 两排栏合成一排：左边返回书架和文档标题，右边是操作。
- 目录、搜索、提问、笔记、排版、导出用「图标 + 文字」；窄屏只留常用项，其余收进「更多」。
- 进度条保留，顶栏收起后仍贴在屏幕顶部。
- 搜索框在点正文、打开面板或离开阅读页时自动收起，滚动看结果时不收起。
- 目录和搜索不同时打开；打开面板时两者都收起。窄屏下打开搜索或目录时，抽屉先隐藏，回答不中断。
- 侧栏的左右分栏和底部抽屉由 `src/app/layout.ts` 决定：竖屏或窗口窄于 1024 像素时用抽屉。不用 CSS 的 orientation，竖屏弹出键盘时布局不能变。
- 阅读位置不能因为顶栏收起而跳动。

### 手指操作

- 所有可点元素的点击区域不小于 44 × 44 像素，视觉上可以小一些。
- 选中工具栏、四色点、快捷提问、面板切换都要达到这个标准。
- 按下时有明确反馈。

### 书架

- 横屏用多列卡片，竖屏两列；显示标题、进度、划线和问答数量、标签。
- 「更新、导出、删除」收进每张卡片的「⋯」菜单。
- 最近读的排在前面，上方加「继续阅读」入口。

### 设置

- 横屏左边是分类导航，右边是内容；竖屏时分类排在上方。
- 分类：AI 接口、阅读、划线颜色、快捷提问、备份与数据、关于。
- 「诊断」移到「关于」里。

### 统一的确认框和反馈

- 新建一个 App 内的确认框组件，替换全部 9 处系统弹窗，跟随三种主题，危险操作用红色按钮。
- 清除全部数据保留两步确认。
- 提示条样式统一，删除划线后可以「撤销」，撤销后划线、批注都恢复。

### 过渡

- 面板、菜单、抽屉、工具栏用 150～200 毫秒的过渡。
- 系统开启「减弱动态效果」时关闭过渡。

### 空状态和首次使用

- 书架为空时说明怎么导入，并提供「打开示例文档」。
- 没配 AI 接口时点提问，直接引导到设置，不只报错。

## 不做

- 不加新功能，不改 Dexie schema，不改备份格式。
- 不引入 UI 库或图标库，图标用内联 SVG。
- 不换字体，不打包新字体。
- 不做手机专门适配。

## 单元测试（必须通过）

- **选中工具栏**：从任何入口打开面板后缓存都被清除；点击正文且选区为空时清除；同一选区晚到的上报被忽略；点工具栏按钮时选区变空，缓存仍在。
- **确认框**：确认、取消、点遮罩的结果正确；危险样式生效；连续调用不串。
- **顶栏收起**：向下滚动收起，向上滚动出现；选中文字、搜索、面板打开时不收起。
- **书架排序和卡片数据**：最近阅读在前；进度、数量正确。
- **撤销删除**：撤销后划线和批注都恢复，位置不变。
- 已有 204 个测试全部通过。

点击区域要靠真实布局才量得出来，单元测试环境没有布局，改在正式构建的浏览器里用脚本检查。
