# 任务 04：第三版（分类与集中整理）

先读 `CLAUDE.md`；`docs/plan.md` 和 `docs/local.md` 存在时也读。第二版已验收并发布 `v0.2.0`，本任务在它的基础上继续，不破坏已有数据和备份格式。

## 目标

读完多篇文档后，笔记能分类、能集中找、集中问；文档改版后划线还在：

- 划线分四种颜色，颜色名称可改；
- 跨文档的全局笔记页，按颜色、标签、关键词筛选；
- 疑问清单：集中看所有红色划线，逐条或批量问 AI；
- 快捷提问可以自定义；
- 文档有新版本时，更新原文并把划线迁移过去。

## 范围

### 四色划线

- 四种颜色固定为 `yellow`、`blue`、`green`、`red`，默认含义：黄色重点、蓝色概念、绿色想法、红色疑问。
- **选中工具栏**：原来的「划线」按钮换成四个颜色点，点哪个就用哪个颜色划线。「批注」用最近一次用过的颜色。颜色点做小，窄屏时工具栏分两行。
- **点击已有划线**：底部工具栏增加四个颜色点，可以改颜色。
- **颜色名称可改**：设置页可以改四种颜色的名称，留空恢复默认。名称用在笔记页、全局笔记页和导出里。
- **显示**：Custom Highlight API 为每种颜色注册一个名称；`<mark>` 回退时每种颜色一个 class。日间、米黄、夜间三种主题下都要看得清，颜色变量写在 `base.css`。
- **旧数据**：已有划线的 `color` 都是 `yellow`，不用迁移。读到不认识的颜色时按 `yellow` 显示，不改数据。
- **导出 md**：引用块下面标出颜色名称，例如 `**分类**：疑问`；只有黄色时也写，格式统一。

### 全局笔记页

- 顶部导航新增「笔记」页，列出所有文档的划线、批注和问答。
- 按文档分组，组内按原文顺序排列。
- 筛选：颜色（可多选）、标签（来自文档的 `tags`）、关键词（搜原文、批注、问答）。筛选条件可以叠加。
- 点一条跳到对应文档的原文位置并闪一下。
- 文档多时不能卡：只在进入页面和筛选变化时计算，关键词输入做防抖。

全局页不渲染文档，所以用锚点里保存的 `quote` 显示原文，U+FFFC 显示为「[公式]」。

### 疑问清单

- 全局笔记页里的一个固定入口，显示所有红色划线，按文档分组。
- 标出每条有没有问过 AI。
- **逐条问**：点一条打开那篇文档和侧栏，原文已带上。
- **批量问**：勾选若干条，填一个问题（默认「解释这段」），一条一条依次问，每条的回答挂回各自的原文，和逐条问的结果一样。每次最多 10 条，开始前显示条数；可以中途停止，失败的可以重试。

### 自定义快捷提问

- 设置页可以增加、删除、修改、排序快捷提问，针对原文和整篇提问各一组。
- 可以恢复默认。
- 每组最多 8 条，每条最多 200 字。
- 一组被清空时，按钮区不显示。

### 文档改版后的划线迁移

- 同名导入保留两份的规则**不变**（`CLAUDE.md` 已定）。迁移是单独的操作。
- 书架每篇文档增加「更新为新版本」：选一个 md 文件或粘贴文本。
- 迁移前先预览：用新文本重新定位所有锚点，显示「能找回 N 处，M 处找不到」，确认后才写入。取消时什么都不改。
- 确认后在一个事务里完成：更新 `documents` 的 `source`、`hash`、`title`，更新锚点的 `start`、`end`、`prefix`、`suffix`、`docHash`。
- 找不到的锚点保持原样，显示在「原文已找不到」分组，数据不删。
- 旧版原文不保留，确认框里提示可以先导出原文或备份。
- 阅读位置按原来所在的文字重新定位，找不到时回到开头。

## 不做

账号和同步、PDF 和 EPUB、手写笔记、笔记之间的双向链接、新增颜色或自定义颜色值。

## 数据模型

沿用 Dexie schema 版本 1，**不需要升级版本号**：`highlights.color` 第一版就有，全局页和疑问清单在内存里筛选，不加索引。

新增设置项（都加进备份白名单 `BACKUP_SETTINGS` 并校验取值）：

- `highlight.colorNames`：四种颜色的自定义名称
- `highlight.lastColor`：最近一次用过的颜色
- `ai.quickPrompts`：自定义快捷提问

`parseBackup` 增加对 `highlights.color` 的校验时，不认识的颜色不能拒绝恢复，否则以后加颜色后旧版本恢复不了；只校验是字符串。

## 单元测试（必须通过）

- 已有的全部单元测试继续通过。
- **颜色**：解析颜色时不认识的值按黄色；改颜色只改 `highlights`；`<mark>` 回退时四种颜色的 class 正确。
- **全局筛选**：颜色、标签、关键词单独和叠加时结果正确；空条件返回全部；公式占位符显示为「[公式]」。
- **疑问清单**：只含红色划线；能标出问过和没问过的。
- **批量问**：串行执行；中途失败不影响已完成的，失败的那条能重试；停止后不再发后面的。
- **快捷提问**：数量和长度限制；清空后恢复默认；备份恢复一致；取值不合法时拒绝恢复。
- **划线迁移**：预览不写数据库；确认后位置正确；找不到的锚点数据不变；事务中途失败时全部回滚；含公式、含 Mermaid、重复句子的文档都要覆盖。
- **导出**：四种颜色和自定义名称的导出结果逐字一致。
- **备份**：v0.1.0、v0.2.0 的备份都能恢复；新设置项随备份恢复。
