# 任务 03：第二版（顺手）

先读 `CLAUDE.md`；`docs/plan.md` 和 `docs/local.md` 存在时也读。第一版（读、问、记闭环）已验收通过并发布 `v0.1.0`，本任务在第一版的基础上把日常阅读和提问体验打磨顺手，不破坏已有数据和备份格式。

## 目标

连续阅读、提问、整理笔记时操作顺畅：

- 书架能看阅读进度、划线数，支持按标签筛选；
- 侧栏提问有预设快捷提问按钮，减少平板横屏打字；
- 支持米黄主题和字号、行距、页边距微调；
- 支持文内搜索；
- 支持 Mermaid 图表渲染（按需加载，不破坏文本映射层和锚点定位），优化公式与表格显示细节；
- 完善平板横竖屏切换与布局细节。

## 范围

### 完整书架（进度、划线数、标签）

- 书架每篇文档卡片增加显示：
  - **阅读进度百分比**（如 `42%`；未读过显示 `未读`，读到底部显示 `100%`）；
  - **划线与笔记数量**（如 `5 处划线 · 2 条问答`）；
  - **标签**（用到时从 `source` 开头的 YAML front-matter 解析 `tags` 字段，不存进数据库；支持 `tags: [数据结构, 树]` 或多行列表写法）。
- 书架顶部增加**标签筛选栏**：列出当前所有文档出现过的标签，点击某个标签只显示含该标签的文档；可切回「全部」。
- **进度计算与持久化**：
  - 映射层总字数只有把文档渲染成 DOM 后才知道，且滚动到底部时屏幕顶部第一个可见字符的位置通常不到全文 100%。
  - 因此在 `DocumentRecord` 新增可选字段 `progress?: number`（`0`～`1`），阅读页滚动保存 `readingPosition` 时把 `progressOf()` 算出的百分比一并写入数据库（当滚动容器已到底部时记为 `1`）。
- 划线数、问答数从现有的表里统计，不新增字段。

### 固定快捷提问

- 在 `AskPanel.vue` 输入框上方增加一排预设快捷提问按钮：
  - **解释这段**
  - **举个例子**
  - **说得更通俗**
  - **和前文有什么关系**
  - **出一道自测题**
- 点击某个快捷按钮时：若正在流式生成则禁用；否则将该预设文本作为问题直接发送（针对整篇提问时，「解释这段」「和前文有什么关系」可自动调整或替换为适合整篇的措辞，如「总结全文重点」「梳理文章脉络」）。
- 「自定义快捷提问」不在本任务范围，留到后续版本。

### 阅读外观（米黄主题、字号、行距、页边距）

- **主题**：在「日间」「夜间」「跟随系统」基础上，增加「**米黄**」（护眼暖色调，正文、代码块、公式、划线、侧栏配色协调清晰）。
- **排版微调**：在阅读页顶部（或设置页 + 阅读页快捷入口）提供：
  - 字号调节（如 `15px` ～ `24px`，默认 `18px`）；
  - 行距调节（如紧凑 `1.6`、标准 `1.8`、宽松 `2.0`）；
  - 页边距 / 正文最大宽度调节（窄、标准、宽）。
- 修改排版参数后立即生效并存入 `settings`；切换字号或行距引起高度变化时，保持当前阅读的字符位置不跳走。

### 文内搜索

- 阅读页顶部增加「搜索」按钮，展开搜索栏：
  - 输入关键词后在当前文档映射层文本（或正文 DOM）中查找所有匹配项；
  - 显示「第 `m` / `n` 处」，提供「上一个」「下一个」按钮和回车跳转；
  - 高亮所有匹配处并滚动到当前选中处（可用 Custom Highlight API 注册独立的搜索高亮名称，或与现有划线机制协调，不污染用户划线数据）；
  - 关闭搜索栏时清除搜索高亮。
- 搜索高亮用独立名称，不进入划线数据。WebView 不支持 Custom Highlight 时划线用 `<mark>` 包裹 DOM，搜索回退时要和划线的 `<mark>` 区分开，清除搜索不能动到划线。

### Mermaid 渲染与文本映射层兼容

- **按需加载**：Mermaid 及其布局引擎体积较大，必须使用动态 `import('mermaid')`，**只有当前文档确实包含 ` ```mermaid ` 代码块时才加载**。
- **PWA 缓存策略（已确认）**：网页版继续全部预缓存，Mermaid 的所有分包也进预缓存，保证带图文档离线可用。首次打开多下载几 MB 可以接受。调大 `maximumFileSizeToCacheInBytes`，保证构建不报错。Service Worker 在后台下载，不影响首屏。App 版资源在本地，不受影响。
- **与文本映射层（TextMap）和锚点定位的兼容（关键要求）**：
  - 渲染后的 `.mermaid` 容器必须像 `.katex` 一样在 `TextMap` 中**作为单字符原子节点（`U+FFFC`）处理**，绝不遍历进入 `<svg>` 内部（SVG 内含大量 `<text>`、`<style>` 等节点，进入会搞乱映射层）。
  - 在 `.mermaid` 容器的 `data-mermaid`（或类似 `data-*`）属性上保留原始 Mermaid 代码块源码。
  - 当 `textWithTex`（或统一的源码还原方法）被复制、发给 AI、导出 md 调用时，把 Mermaid 对应的 `U+FFFC` 换回原始的 ` ```mermaid ... ``` ` 代码块文本，保证上下文和复制内容完整。
  - 主题切换（日间 / 米黄 / 夜间）时，Mermaid 图表配色随之适配，保证深色背景下线条和文字看得清。
  - Mermaid 语法错误时优雅降级：显示原始代码块并附简短错误提示，不抛出未捕获异常，不中断整篇文档渲染。
- **旧数据的处理**：v0.1.0 里 Mermaid 源码按文字计入映射层，升级后有两种影响，都不能丢数据：
  - 落在 Mermaid 代码块内部的划线（当时选中的是代码文字）会变成孤立锚点，保留数据，显示在「原文已找不到」分组。
  - 图后面的锚点位置整体前移，靠 `quote` 全文搜索重新定位；紧挨着图的锚点，`prefix`/`suffix` 里有 Mermaid 源码，相似度会下降，要有测试覆盖。

### 公式、表格与横竖屏细节

- **公式与表格**：长公式块（`$$...$$`）和宽表格支持平滑横向滚动，不撑破正文容器，也不触发整页横向晃动。
- **横竖屏适配**：
  - 横屏时正文在左、侧栏在右并排；竖屏时侧栏作为底部抽屉拉起，高度合理，键盘弹出时输入框不被遮挡。
  - 旋转屏幕或窗口尺寸变化（`resize`）时，保持当前阅读段落位置，底部工具栏位置正常更新。

## 不做

四色划线分类、全局跨文档笔记页、疑问清单、批量提问、自定义快捷提问、文档改版后的划线迁移。

## 数据模型

沿用 Dexie schema 版本 1，**不需要升级版本号**（主键与索引均不变）：

- `DocumentRecord` 新增可选字段 `progress?: number`（`0`～`1` 的阅读进度百分比）。标签和划线数都不存，用到时计算。
- 新增设置项：
  - `ui.theme`：允许值扩展为 `'light' | 'sepia' | 'dark' | 'system'`
  - `ui.fontSize`、`ui.lineHeight`、`ui.pageWidth`（排版微调参数）
  - 这些新设置都要加进备份的设置白名单（`src/db/backup.ts`），并校验取值；`ui.theme` 的校验要接受 `sepia`。
- 备份与恢复：`parseBackup` 保持对旧备份（无 `progress` 字段）的向后兼容，导出与恢复时保留这个可选字段；`progress` 存在时要校验是 `0`～`1` 的数字。

## 单元测试（必须通过）

- 第一版已有的全部单元测试继续通过。
- **YAML 标签解析**：从 front-matter 提取行内数组 `tags: [a, b]`、多行列表 `tags:\n  - a\n  - b`、无 front-matter 等情况。
- **文本映射层与 Mermaid**：
  - `.mermaid` 容器在 `TextMap.text` 中只占 1 个字符（`U+FFFC`），不进入 `<svg>` 内部；
  - 还原文本时能把 `.mermaid` 换回原始 Mermaid 代码块；
  - 选区边界落在 `.mermaid` 内部时扩展到整个 `.mermaid` 外层元素。
- **文内搜索**：关键词匹配位置计算、大小写不敏感匹配、当前命中项切换（上一个/下一个循环）、空关键词处理。
- **备份兼容**：含 `progress` 的文档备份导出与恢复一致；v0.1.0 导出的备份仍能完整恢复。
- **Mermaid 与旧锚点**：图前后的锚点重新定位正确；落在代码块内部的锚点标记为孤立，不报错、不删数据。
