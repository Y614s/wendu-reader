# 问读

一个开源的安卓平板 Markdown 阅读器：读、问、记在同一个界面完成。

选中文字后，底部弹出工具栏，可以划线、在侧栏向 AI 提问，或者把内容发给 Claude、豆包等 AI App。划线和问答都会保存下来，挂在原文上。

> 目前处于**技术验证阶段**，功能还不完整，仅供试用。

## 下载安装

到 [Releases](https://github.com/Y614s/wendu-reader/releases) 页面下载最新的 `wendu-reader-*.apk`，在平板上打开安装（需要允许“安装未知应用”）。

新版本直接覆盖安装即可，本地数据会保留。

## 首次配置

1. 打开「设置」，选择一个服务商预设（默认 DeepSeek），或选「自定义」填入任何兼容 OpenAI Chat Completions 格式的接口。
2. 填写模型名和你自己的 API Key。
3. 到「诊断」页点「测试连通」，确认能收到流式回答。

## 隐私

- 没有服务器、没有账号、没有任何统计或上报。
- 文档、划线、笔记和对话只存在你自己的设备上。
- API Key 只保存在本机，不会进入备份文件。
- 你的问题和相关原文只会发给你自己选择的 AI 服务商，不会发往其他任何地方。

## 自己构建

fork 本仓库后，按 [docs/setup.md](docs/setup.md) 配置签名密钥，GitHub Actions 会自动构建出你自己的 APK。
