# 问读

一个开源的安卓平板 Markdown 阅读器：读、问、记在同一个界面完成。

选中文字后，底部弹出工具栏，可以划线、写批注、在侧栏向 AI 提问，或者把内容发给 Claude、豆包等 AI App。划线、批注和问答都挂在原文上，可以在笔记侧栏里按原文顺序查看，最后导出成 md。

> 目前是**第二版**：读、问、记的流程已经完整，四色划线、全局笔记等会在后续版本加入。

## 下载安装

到 [Releases](https://github.com/Y614s/wendu-reader/releases) 页面下载最新的 `wendu-reader-*.apk`，在平板上打开安装（需要允许“安装未知应用”）。

新版本直接覆盖安装即可，本地数据会保留。

## 首次配置

1. 打开「设置」，选择一个服务商预设（默认 DeepSeek），或选「自定义」填入任何兼容 OpenAI Chat Completions 格式的 https 接口。
2. 填写模型名和你自己的 API Key，保存。Key 保存后在界面上不能再查看，只能更改或删除。
3. 到「诊断」页点「测试连通」，确认能收到流式回答。

## 怎么用

- **书架**：显示阅读进度、划线和问答数量；文档开头 YAML 里写了 `tags` 时可以按标签筛选。
- **导入**：在「书架」导入 md 文件或粘贴文本；也可以在微信等 App 里选「用其他应用打开」→「问读」。
- **阅读**：自动记住读到哪里；「目录」跳转章节，「搜索」查找本文内容，「排版」切换主题（日间、米黄、夜间）和调整字号、行距、正文宽度。
- **图表**：`mermaid` 代码块渲染成图，复制、提问和导出时带的是原始代码。
- **选中文字后**：
  - 划线；
  - 批注：划线并写一段想法；
  - 侧栏问：用你配置的 AI 接口提问，可以选只带「本节」还是「全文」作为上下文；有「解释这段」等快捷提问，点一下就发送；回答里的任意一段都能存为笔记；
  - 发到 App：把原文发给其他 AI App，回来后把回答粘贴到「待补充」记录里；
  - 复制：复制原文，附带文档名和章节。
- **整篇提问**：不选文字，直接点阅读页顶部的「整篇提问」。
- **笔记**：阅读页顶部的「笔记」按原文顺序列出本文的划线、批注和问答，点一下跳回原文。

## 导出与备份

- **导出**：阅读页顶部的「导出」可以导出笔记（按章节整理，可以直接放进 Obsidian）或原文。
- **备份**：「设置 → 备份与恢复」一键导出 json，包含所有文档、划线、批注、对话和阅读设置，**不含 API Key 和 AI 接口配置**，换设备后要重新填写。超过 7 天没备份会提醒一次。
- **恢复**：可以选「合并」（本机已有的保留本机的）或「替换」（本机数据全部换成备份里的）。文件有问题时不会改动现有数据。只恢复自己导出的备份。

数据只存在本机。换设备、卸载重装或清除数据之前，请先导出备份。

## 隐私

- 没有服务器、没有账号、没有任何统计或上报。
- 文档、划线、笔记和对话只存在你自己的设备上，不参与系统的云备份和换机迁移。
- API Key 只保存在本机，保存后界面上不再显示，也不会进入备份文件。
- 你的问题和相关原文只会发给你自己选择的 AI 服务商，不会发往其他任何地方。
- 文档里的外部图片默认不加载，点一下才加载那一张。加载时图片所在的服务器能看到你的 IP。
- 文档和 API Key 以明文保存在本机，靠安卓的应用隔离保护，没有另外加密。已 root 的设备上其他程序可能读到。
